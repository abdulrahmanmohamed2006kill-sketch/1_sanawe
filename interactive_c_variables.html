مقدمة: ما هو المتغير Variable؟

تخيل إنك بتنقل لبيت جديد، وعندك صناديق كتير عشان تحط فيها حاجاتك. المتغير (Variable) في البرمجة بالظبط زي الصندوق ده. بنستخدمه عشان نحفظ جواه قيمة (Value) معينة في ذاكرة الكمبيوتر عشان نستخدمها بعدين.

أي صندوق (متغير) لازم يكون له 3 حاجات أساسية:

  • نوع (Data Type): بيحدد إيه اللي ينفع يتحط جوه الصندوق (أرقام، نصوص، حروف).
  • اسم (Name): عشان نقدر نلاقي الصندوق ده بسهولة وسط صناديق كتير.
  • قيمة (Value): الشيء اللي بنخزنه فعلياً جوه الصندوق.

اضغط على الصندوق عشان تشوف اللي جواه!

age (الاسم)
20 int (النوع)

في لغة C++، بنكتب كود إنشاء الصندوق ده بالشكل التالي:

int age = 20 ;

اضغط على أي جزء من الكود فوق عشان تفهم معناه.

إزاي نعرف متغير؟ (Variable Declaration)

عشان تعرف متغير جديد في C++، فيه قاعدة أساسية بنمشي عليها من الشمال لليمين:

DataType VariableName = Value ;

الطريقة الأولى: التعريف ثم الإسناد

بنعمل الصندوق الأول، وبعدين نحط فيه القيمة في سطر تاني.

int age;
age = 20;

الطريقة التانية: كله في سطر واحد

بنعمل الصندوق ونحط فيه القيمة في نفس الوقت (ودي الطريقة الأفضل والأكثر استخداماً).

int age = 20;

تحذير مهم جداً

لو عملت متغير وماحطيتش فيه قيمة ابتدائية (زي السطر الأول في الطريقة الأولى)، الكمبيوتر بيحط فيه قيمة عشوائية (Garbage Value) من الذاكرة. ممنوع تستخدم المتغير أو تقرأ قيمته قبل ما تحط فيه قيمة صريحة بنفسك!

النوع الأول: int (Integer)

نوع البيانات int مخصص للأعداد الصحيحة فقط. يعني أرقام مفيهاش أي كسور عشرية، سواء كانت موجبة أو سالبة أو صفر.

أمثلة صحيحة:

int students = 30; // عدد صحيح موجب
int temperature = -5; // عدد صحيح سالب

اختبر نفسك: أي من القيم دي تنفع تكون int؟

النوع الثاني: double

نوع البيانات double بيستخدم لتخزين الأرقام اللي فيها كسور عشرية، وسموه كدة عشان هو بيوفر دقة مضاعفة (Double Precision) في تخزين الكسور.

أمثلة لاستخدام double:

double salary = 15000.75;
double height = 175.5;
double price = 99.99;

معلومة عالماشي

عادي جداً تحط رقم صحيح جوه double (مثلاً double x = 10;)، الكمبيوتر هيعامله كأنه 10.0.

النوع الثالث: float

الـ float أخو الـ double الصغير. بيخزن برضه أرقام عشرية، بس بدقة أقل، وبياخد مساحة أصغر في الذاكرة.

الشرط الأساسي: عشان تعرف الكمبيوتر إن الرقم ده float مش double، لازم تحط حرف f أو F في آخر الرقم.

float temperature = 36.5f;
float price = 15.75f;

float

  • دقة أقل (حوالي 7 أرقام عشرية)
  • مساحة أقل في الذاكرة (عادة 4 بايت)
  • لازم ينتهي بحرف f

double

  • دقة أعلى (حوالي 15 رقم عشري)
  • مساحة أكبر في الذاكرة (عادة 8 بايت)
  • لا يحتاج أي حروف في النهاية

النوع الرابع: string

بنستخدم string عشان نحفظ نصوص (كلمة، جملة، أو حتى نص فاضي).

قاعدة مهمة: أي نص لازم يتحط بين علامتين تنصيص مزدوجتين " " (Double Quotes).

string name = "Abdulrahman";
string city = "Mansoura";
string message = "Hello World";

إيه الفرق لو مكتبناش علامات التنصيص؟

الكمبيوتر هيفتكر إن الكلمة دي اسم متغير تاني مش نص، وهيطلعلك خطأ (Error) لو المتغير ده مش موجود!

string name = Abdulrahman; // ❌ ERROR

تجهيز الـ string

عشان نقدر نستخدم string في C++ بسهولة، لازم نكتب السطرين دول في أول الملف بتاعنا فوق خالص:

#include <string>
using namespace std;

النوع الخامس: char (Character)

الـ char بيشيل حرف واحد فقط لا غير. ممكن يكون حرف إنجليزي، رقم، أو رمز.

قاعدة مهمة: الحرف لازم يتحط بين علامتين تنصيص مفردتين ' ' (Single Quotes).

char grade = 'A'; // حرف
char gender = 'M'; // حرف
char symbol = '#'; // رمز
char numberAsChar = '7'; // رقم يُعامل كحرف وليس قيمة رياضية
