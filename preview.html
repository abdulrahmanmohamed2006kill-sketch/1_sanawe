SIGNING PIPELINE

أنت (المرسل) عندك مفتاحين: Public Key (بتوزعه للناس) و Private Key (سرّي بتاعك أنت بس). بنستخدم المفتاح السري عشان نمضي البصمة.

🧠 الفكرة في 3 حركات
① الرسالة → Hash
نحوّل الرسالة لبصمة ثابتة.
② Hash → Private Key
عبدالرحمن يوقّع البصمة بمفتاحه السري.
③ Public Key → Verify
محمد يتحقق من التوقيع ويقارنه بالـHash الجديد.
