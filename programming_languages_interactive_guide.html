لغة البرمجة هي مجرد أداة TOOL

لغة البرمجة ليست سحراً، بل هي **أداة (TOOL)** تساعدكِ في كتابة تعليمات وأوامر للحاسوب لتنفيذ مهمة معينة. التعليمات التي تكتبينها تُسمى **Code**!

📌 النتيجة: الحاسوب يُنفذ الأوامر 💻
⚡

لغة الآلة (Machine Language)

هي اللغة الوحيدة التي يفهمها المعالج مباشرة بدون وسيط! تتكون من أرقام ثنائية **Binary (0s & 1s)** أو سداسية عشرية **Hexadecimal** مثل `0x55 0x89`.

01001000 01100101 01111001 1 & 0
⚙️

لغة التجميع (Assembly)

لغة منخفضة المستوى تستخدم اختصارات نصية قصيرة (مثل `MOV`, `PUSH`, `ADD`) لتسهيل القراءة مقارنة بالأصفار والآحاد المباشرة.

push %ebp | mov %esp 🎀
👑

اللغات عالية المستوى

مثل Python, C++, Java, JS, C#. قريبة جداً من لغة البشر وسهلة القراءة والكتابة مثل: PRINT "Hello World"!

سهلة للبشر ، تحتاج مترجم للآلة ✨
📜

Source Code vs Object Code

• **Source Code:** الكود الذي تكتبينه بلغة عالية المستوى.
• **Object Code:** الكود المترجم إلى لغة الآلة جاهز للتنفيذ!

Source (بشري) ➔ Object (آلة) 🔄
🔮

المترجم والمفسر Translator

الحاسوب لا يفهم لغتك المباشرة! لذا نحتاج برامج ترجمة **(Compiler أو Interpreter)** تحول الكود المصدر (Source) إلى كود آلة (Object).

Compiler / Interpreter 🎀
🧪 معمل المترجم السحري T-Lab 🎀

كيف يتحول كودكِ اللطيف إلى لغة الآلة؟

اختر لغة البرمجة، واضغطي زر الترجمة لرؤية مراحل تحول الكود خطوة بخطوة!

المرحلة 1: Source Code 🌸
كود عالي المستوى (بشري) High-Level 
PRINT "Hello, World!"
المرحلة 2: Assembly Code ⚙️
لغة التجميع (وسيطة) Low-Level 
اضغطي زر الترجمة للمعالجة...
المرحلة 3: Object Code / Machine ⚡
لغة الآلة (Binary & Hex) 0s & 1s 
01001000 01100101 01111001...
جاهز لتجربة الترجمة السحرية! اختر لغتكِ واضغطي الترجمة. 👑

المستوى المحدد

Scripting / Interpreted Languages

🐍

لغات مثل بايثون وجافاسكريبت سهلة جداً للقراءة للبشر ومرنة. لكنها تعتمد على Interpreter ينفذ السطور واحداً تلو الآخر مما يجعلها أبطأ في التنفيذ مقارنة باللغات الأدنى.

سهولة القراءة للبشر (Readability) 📖 عالية جداً (95%)
سرعة التنفيذ (Execution Speed) ⚡ بطيئة نسبياً (30%)
💡 **قاعدة ذهبية:** كلما ارتفعت لغة البرمجة (High Level)، زادت سهولة قراءتها وقلت سرعة تنفيذها، والعكس صحيح!
العتاد المباشر (Hardware) 🎀 لغات عالية جداً
💻 محول الآلة اللطيف (Text ➔ Binary) 🎀

كيف يرى الحاسوب أفكاركِ ونصوصكِ؟

اكتبي أي كلمة أو جملة باللغة الإنجليزية ورؤية تحولها الفوري إلى أصفار وآحاد (Binary Code)!

الترميز الثنائي Binary (0s & 1s)

01001000 01100101 01101100 01101100 01101111 00101100 00100000 01010111 01101111 01110010 01101100 01100100 00100001

الترميز السداسي عشر Hexadecimal

48 65 6C 6C 6F 2C 20 57 6F 72 6C 64 21

✨ هذه هي الطريقة التي يُخزن بها المعالج النوايا والأرقام والرموز في الذاكرة!
