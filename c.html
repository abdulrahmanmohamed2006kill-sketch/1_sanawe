الدرس الأول

مقدمة عن شكل برنامج C++

أهلاً بيك في عالم البرمجة! تعال نشوف البرنامج البسيط ده بيتكون من إيه.

الكود اللي قدامك ده بيطبع كلمة "Hello World" على الشاشة. متتخضش من شكله، البرنامج بيتكون من أجزاء زي المكعبات، وكل جزء ليه وظيفة. اضغط على أي سطر في الكود عشان تفهم معناه:

#include <iostream>

int main()
{
std::cout << "Hello World";

return 0;
}

الدرس الثاني

يعني إيه مكتبات (Libraries)؟

تخيل إنك نجار وعندك صندوق أدوات 🧰. كل أداة بتساعدك تعمل حاجة معينة (شاكوش للمسامير، منشار للخشب).

في الـ C++، المكتبات (Libraries) هي عبارة عن ملفات جاهزة فيها "أدوات" المبرمجين اللي قبلنا عملوها عشان تساعدنا ننفذ وظائف بسهولة من غير ما نخترع العجلة من جديد!

صندوق الأدوات = المكتبة

عشان تستخدم أداة، لازم الأول تجيب الصندوق بتاعها.

تفصيل أمر إدراج المكتبة

عشان نقول للبرنامج "هات المكتبة دي"، بنستخدم أمر #include. اضغط على الأجزاء:

(اضغط على الكلمات فوق لمعرفة وظيفتها)

المكتبات الأساسية للمبتدئ

هنتعرف دلوقتي على أهم صندوقين أدوات هنحتاجهم في البداية.

<iostream>

مكتبة الإدخال والإخراج القياسية (Input/Output Stream).

دي المكتبة اللي فيها أدوات الطباعة على الشاشة (الإخراج)، وأدوات استقبال بيانات من الكيبورد (الإدخال).

cout : أداة الطباعة (النهارده تركيزنا عليها).
cin : أداة الإدخال.
#include <iostream>

<string>

مكتبة النصوص والكلمات.

لو عايز البرنامج بتاعك يتعامل مع نصوص (زي اسم شخص مثلاً)، لازم تجيب مكتبة النصوص عشان توفرلك نوع البيانات string.

#include <string>
std::string name = "Ahmed";

ملاحظة: دايماً ضيف مكتبة string صراحة لو هتستخدم نصوص.

نشاط سريع: اسحب وافلت (أو اضغط للاختيار)

عايز أطبع رسالة ترحيب على الشاشة، أستخدم مكتبة إيه؟

يعني إيه std:: ؟

دي أهم نقطة عشان تفهم الطباعة صح!

كلمة std هي اختصار لـ Standard (القياسي). تخيل إن جوا المكتبات الكبيرة دي، فيه "أدراج" أو "غرف" منظمة، بنسميها مساحة الأسماء (Namespace).

std
cout
cin
string

صندوق الأدوات القياسي (std) بيحتوي على أدوات زي cout.

لما نحب نستخدم أداة cout من الصندوق ده، لازم نقول للمترجم الأول: "هات الصندوق اللي اسمه std، ومن جواه هات الأداة cout". بنكتبها كدة:

std :: cout

(اضغط على كل جزء للشرح)

الطريقة الأولى: استخدام std:: صراحةً

دي الطريقة الأساسية. قبل أي أداة من أدوات C++ القياسية، بنكتب std::.

#include <iostream>

int main()
{
    
    

    return 0;
}

إيه هي علامة << ؟

ده اسمه معامل إدراج البيانات (Insertion Operator). تخيل إنه سهم بياخد الكلام (زي "Ahmed") ويرميه جوا الشاشة (cout).

الطريقة الثانية: استخدام using namespace std;

المشكلة:

تخيل إنك بتعمل برنامج كبير وكل سطر فيه طباعة لازم تكتب قبله std::، الموضوع هيبقى متعب الكود هيبقى زحمة.

الحل الأسهل:

ممكن في أول البرنامج نقول للمترجم: "يا عم أنا هستخدم صندوق std على طول، أي أداة اكتبها لك لو ملقتهاش دور عليها جوا الصندوق ده". وبنكتبها كدة:

using namespace std;
  • using: نريد استخدام.
  • namespace: مساحة أسماء.
  • std: اللي اسمها std.
الكود الجديد #include <iostream>

using namespace std;

int main()
{
    /* كتبنا cout على طول من غير std:: */
    cout << "Hello";
    cout << "Welcome";

    return 0;
}
مهم جداً: السطر ده بيلغيش المكتبة! لسه لازم نكتب #include <iostream> في الأول. هو بس بيوفر علينا كتابة std:: كل شوية.

مقارنة بين الطريقتين

امشي بالماوس على سطور الكود وشوف الاختلاف بين الطريقتين.

الطريقة الأولى (std::)

#include <iostream>


int main() {
std::cout << "Hi";
return 0;
}
  • نكتب std:: قبل الأداة.
  • أكثر تحديداً ودقة.
  • أفضل في المشاريع الكبيرة (عشان أسماء الأدوات متدخلش في بعض).

الطريقة الثانية (using)

#include <iostream>
using namespace std;

int main() {
cout << "Hi";
return 0;
}
  • نستخدم الأداة cout مباشرة.
  • أقل في الكتابة وأسرع.
  • مناسبة للمبتدئين والأمثلة الصغيرة.

الطريقتين صح 100%، وتقدر تستخدم اللي تريحك!
