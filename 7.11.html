النظام الثماني في الحاسوب (Octal System)

دليل شامل لفهم النظام الثماني، أوزان الخانات، طريقة التحويل المباشر لـ 3-bit Binary، وتاريخ استخدامه في العتاد القديم مقابل النظام السداسي عشر Hexadecimal.

أساسيات النظام الثماني (Base-8)

القواعد الرئيسية ومكونات النظام

الأرقام المتاحة

يتكون من 8 رموز فقط: 0, 1, 2, 3, 4, 5, 6, 7. لا يوجد الرقم 8 أو 9 مطلقاً في هذا النظام.

أوزان الخانات

قوى العدد 8:
8⁰ = 1, 8¹ = 8, 8² = 64, 8³ = 512, 8⁴ = 4096...

مثال توضيحي للفك الرياضي: 512₈ ➔ Decimal

Value = (2 × 8⁰) + (1 × 8¹) + (5 × 8²)

Value = (2 × 1) + (1 × 8) + (5 × 64)

Value = 2 + 8 + 320 = 330₁₀

العلاقة بين الثنائي والثماني (3-Bit Grouping)

لماذا تم استخدام النظام الثماني في الحاسوب؟

لأن 2³ = 8، فإن كل رقم ثماني واحد يمثل بدقة مجموعة من 3 بتات ثنائية (3-bits). هذا جعل التحويل بينهما سهلاً وسريعاً جداً دون الحاجة لعمليات قسمة طويلة.

لماذا يقل استخدام النظام الثماني حالياً؟ (Octal vs Hex)

قديمةً، كانت المعالجات تعتمد على كلمات بحجم 12-bit أو 18-bit أو 36-bit (وهي مضاعفات الرقم 3)، فكان النظام الثماني مثالياً. أما اليوم، فتعتمد المعالجات على البايت القياسي (8-bit, 16-bit, 32-bit, 64-bit) وهي مضاعفات الرقم 4، لذلك أصبح النظام السداسي عشر Hexadecimal (4-bit nibbles) هو النظام الأكثر انتشاراً في تمثيل عناوين الذاكرة والألوان (HEX Codes).

المحاضرة الثانية: شبكات الحاسوب

أساسيات شبكات الحاسوب (Networks Part I)

مفهوم الشبكات، فوائد الاتصال ومشاركة الموارد، المقارنة بين LAN و WAN، وسائط الاتصال السلكية واللاسلكية، البروتوكولات، ومعنى كلمة Wi-Fi.

ما هي شبكة الحاسوب (Computer Network)؟

هي ربط جهازين أو أكثر معاً عبر وسيط أجهزة سلكي أو لاسلكي بغرض تبادل البيانات ومشاركة الموارد (مثل المطبوعات والتخزين) والتواصل والتفاعل.

الشبكة المحلية (LAN)

Local Area Network: تغطي مساحة جغرافية صغيرة محدودة مثل المنزل، المعمل، أو المكتب. تتميز بسرعات فائقة وأمان عالٍ.

الشبكة الموسعة (WAN)

Wide Area Network: تربط شبكات محلية متعددة عبر مدن أو دول كاملة. أكبر مثال حي عليها هو شبكة الإنترنت (Internet).

وسائط التوصيل وحقيقة كلمة Wi-Fi

1. الاتصال السلكي (Wired Connection):
  • كابلات الإيثرنت (Ethernet Cables / Twisted Pair).
  • كابلات الألياف الضوئية (Fiber Optics) ذات السرعة الخيالية.
2. الاتصال اللاسلكي (Wireless Connection):
  • موجات الراديو والواي فاي (Wi-Fi).
  • البلوتوث (Bluetooth) والأقمار الصناعية (Satellites).
المعلومة الهامة: ماذا يعني اختصار Wi-Fi؟

ترمز كلمة Wi-Fi رسمياً إلى Wireless Fidelity (الأمان أو الدقة اللاسلكية)، وهو مصطلح تسويقي تم ابتكاره للتعبير عن معايير الاتصال اللاسلكي IEEE 802.11.

المحاضرة الثالثة: مستويات البرمجة

مستويات لغات البرمجة (Language Levels)

فهم التدرج في لغات البرمجة من لغة الآلة والتجميع إلى اللغات عالية المستوى والسكربتات، ومقاييس القرب من العتاد والسهولة والسرعة.

التصنيف الثلاثي لمستويات اللغات

1. لغات متدنية المستوى (Low-Level Languages)

أقرب للعتاد

• لغة الآلة (Machine Language): الشفرة الثنائية (010101) المفضلة للـ CPU مباشرة دون ترجمة.
• لغة التجميع (Assembly Language): تستخدم اختصارات رمزية (Mnemonics) مثل `MOV`, `ADD`, `SUB`.

2. لغات عالية المستوى (High-Level Languages)

سهلة للبشر

تستخدم كلمات إنجليزية قريبة لفهم الإنسان وتراكيب رياضية. أمثلة: C++, Java, C#. تتطلب مترجماً لتحويلها إلى آلة.

3. لغات السكربت (Scripting Languages)

سرعة التطوير

لغات عالية المستوى جداً وتُنفذ غالباً عبر مفسر (Interpreter) سطر بسطر. أمثلة: Python, JavaScript, PHP.

المصطلحات المحورية: Source Code vs Object Code

📄 Source Code (الشفرة المصدرية)

الكود النصي المكتوب بلغة برمجية يفهمها المبرمج البشري (مثل ملف main.cpp أو script.py).

⚙️ Object Code (الشفرة الهدف)

الكود المترجم بلغة الآلة الثنائية (Binary) الجاهز ليفهمه المعالج مباشرة ويُحفظ كـ binary أو .exe.

المحاضرة الرابعة: الترجمة والتفسير

المترجم والمفسر (Compiler vs Interpreter)

دورة حياة الكود، الفرق بين تجميع الكود دفعة واحدة المخرج لملفات `.exe` وبين التفسير التتابعي خطوة بخطوة، والفرق مع الـ Assembler.

المقارنة التفصيلية المباشرة

وجه المقارنة المترجم (Compiler) المفسر (Interpreter)
طريقة العمل يترجم البرنامج بالكامل دفعة واحدة ينفذ الكود سطرًا بسطر مباشرة
إنتاج ملف تنفيذي (.exe) نعم (يُخزن Object Code بالقرص) لا (لا ينشئ ملفات مستقلة)
سرعة التنفيذ اللاحقة سريعة جداً (Machine Code جاهز) أبطأ نسبياً (يترجم كل مرة)
اكتشاف الأخطاء يعرض كافة الأخطاء بعد فحص الملف كاملًا يتوقف فورًا عند أول سطر يحتوي خطأ
أمثلة اللغات C, C++, Rust, Swift Python, JavaScript, Ruby

ما هو برنامج المجمّع (Assembler)؟

هو برنامج مُترجم خاص باللغات متدنية المستوى، وظيفته المحددة هي تحويل الشفرة الرمزية المكتوبة بلغة التجميع (Assembly Language) إلى لغة الآلة الثنائية (Machine Code).

واجب المحاضرة 1: النظام الثماني

3 مسائل

س1: حول الأرقام الثمانية (100₈ و 512₈) إلى النظام العشري؟

• 100₈ = (0×8⁰) + (0×8¹) + (1×8²) = 64₁₀
• 512₈ = (2×8⁰) + (1×8¹) + (5×8²) = 2 + 8 + 320 = 330₁₀

س2: حول الأرقام العشرية (64₁₀ و 330₁₀) إلى ثماني؟

• 64 ÷ 8 = 8 (الباقي 0) ➔ 8 ÷ 8 = 1 (الباقي 0) ➔ 1 ÷ 8 = 0 (الباقي 1) ➔ 100₈
• 330 ÷ 8 = 41 (الباقي 2) ➔ 41 ÷ 8 = 5 (الباقي 1) ➔ 5 ÷ 8 = 0 (الباقي 5) ➔ 512₈

س3: حول الثماني (100₈ و 512₈) إلى ثنائي مباشر (3-Bit)؟

• 100₈ ➔ 1(001) | 0(000) | 0(000) = 001000000₂ (أو 1000000₂)
• 512₈ ➔ 5(101) | 1(001) | 2(010) = 101001010₂

واجب المحاضرة 2: الشبكات

2 سؤالين

What is Network & Why do we need it?

الشبكة هي مجموعة من الأجهزة المرتبطة معاً بوسيط سلكي أو لاسلكي. نحتاجها لنقل البيانات بسرعة، مشاركة الأجهزة الملحقة (الطابعات/السيرفرات)، والتواصل الفوري بين النظم.

LAN vs WAN & Wi-Fi Meaning:

• LAN: شبكة محلية لمبنى أو منزل محدود.
• WAN: شبكة موسعة ترتبط بها شبكات حول العالم كالانترنت.
• Wi-Fi: اختصار مصطلح Wireless Fidelity.

واجب المحاضرة 3: مستويات اللغات

مفاهيم

Source Code vs Object Code & Readability vs Speed:

• Source Code هو الكود البشري المكتوب بلغة برمجة، بينما Object Code هو الكود المترجم إلى ثنائي الآلة.
• كلما كانت اللغة أكثر قراءة للبشر (Human Readable) كلما ابتعدت عن العتاد وتطلبت ترجمة أكبر، وكلما اقتربت من الآلة (Assembly/Machine) كانت أسرع في التنفيذ المباشر.

خلاصة الأسئلة المقارنة:

• هل يُنتج المفسر ملف exe؟ لا.
• هل يحفظ المفسر Machine Code على القرص؟ لا.
• هل يُنتج المترجم ملف exe؟ نعم.
